# Curated derived results

This directory contains the compact set of derived tables used to audit the manuscript's main statistical claims. The raw market-price panel and third-party index documents are intentionally excluded; see `../data/README.md`.

The public notebook regenerates these tables and additional diagnostic outputs. The archived tables here preserve the results used in manuscript preparation, including snapshot topology, Monte Carlo edge-length inference under two null models, topology-null diagnostics, edge-bootstrap support, MRQAP, stationarity, targeted robustness, and CNBV regulatory triangulation.
